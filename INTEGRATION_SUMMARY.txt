═══════════════════════════════════════════════════════════════
  HOW IT WORKS
═══════════════════════════════════════════════════════════════

FLOW:
1. User starts test → Bot asks "Name and age?" 
   → User responds (text/image/voice) ✓

2. Bot asks "Tell me about yourself"
   → User responds (text/image/voice) ✓

3. Profile Extractor Agent runs:
   - Loads existing profile (if exists)
   - Analyzes conversation:
     * Q: "Name and age?" A: "I'm Ali, 25"
     * Q: "About yourself?" A: "Software engineer, love coding"
   - Extracts structured profile
   - Decides action (create/refine/update)
   - Saves to database/user_profiles/

4. Profile used in:
   - Test personalization
   - Smart chat context
   - User profile display
   - Future sessions
